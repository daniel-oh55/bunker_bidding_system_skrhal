# Legacy Firebase Prototype

This directory preserves the original Firebase-based prototype as a reference artifact.

- It does not contain production data.
- It is not an active maintenance target.
- It must not be imported into the active application.
- It exists so the team can reference prior UI, workflow, email, and manual calculation behavior while rebuilding on Supabase V2.

Do not modernize, secure, or partially migrate files in this folder during foundation work.
